# Compendio Totale D&D 5e

Compendio single-page in italiano basato sul System Reference Document 5.1,
pensato per essere consultato durante le sessioni di gioco.

## Contenuti
- Razze, tratti, classi con tabella 1–20, sottoclassi e privilegi
- Incantesimi e trucchetti con filtri per classe, livello e scuola
- Mostri, oggetti magici, equipaggiamento, regole e condizioni

## Funzioni
- Ricerca istantanea multi-parola (scorciatoia `/`) e filtri avanzati manuali
- Grimorio rapido (preferiti), tiradadi animato con vantaggio/svantaggio
- Contatori risorse con riposo breve/lungo
- Creatore Homebrew, copia rapida delle regole per Discord/Roll20/Foundry

## Uso
Apri `index.html` in un browser. Nessuna installazione né connessione richiesta.

## Note sui contenuti
Alcune voci (backgrounds, talenti e condizioni non presenti nel PDF SRD)
sono marcate "Integrazione (fuori dal PDF)" e vanno verificate sul manuale.
